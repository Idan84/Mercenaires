Tous les tags possibles

Un tag peut avoir plusieurs parents : il apparaît sous chacun. S'il perd un seul de ses parents, il est éliminé aussi.

    Le tag choisi

    Choisissez un tag pour le renommer, lui donner un ou plusieurs parents, ou lui ajouter des enfants.

    Rempli, seuls les X tags de plus haut rang qui restent s'affichent (à rang égal, l'ordre de la liste). Vide : le tag le plus bas de chaque branche.

    Sert dans une catégorie limitée : le rang le plus haut s'affiche.

    Les tests, dans l'ordre

    Chaque test pose une question sur le mercenaire. Sa réponse élimine des tags, et avec eux tous leurs enfants. Un test peut être rangé sous la réponse d'un autre : il n'est posé que si cette réponse sort.

    Constantes : des valeurs nommées que les calculs utilisent (un seuil se change ici, une seule fois)

      Le test choisi

      Choisissez un test, ou créez-en un.

      Quand il n'est pas posé, ce test n'élimine rien : élimine ses tags dans la réponse qui le saute.
