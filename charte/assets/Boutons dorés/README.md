# Boutons dorés

Le kit doré d'Idan (2026-11-25) : cadre doré et velours rouge (la couleur par défaut). Chaque pièce existe en trois couches :
`<nom>-rouge` (tout), `<nom>-cadre` (l'or seul, velours transparent), `<nom>-velours` (le velours seul, à teinter).

- `bouton-*` (1200 × 266) : le bouton large aux pans coupés (remplace `Interface/bouton.webp`, en plus fin).
- `rond-*` (581 × 600) : le bouton rond ; `carre-*` (594 × 600) : le bouton carré aux pans coupés.
- `fleche-rouge|cadre|velours-gauche|droite|haut|bas` : les flèches-boutons (pages, carrousels, défilement).
- Le velours se teinte : brun (filtre), ou la couleur de la culture (le velours en niveaux de gris, la couleur posée en mode « couleur »).
- Auteur : Idan.
