Registres transversaux utilisés par le moteur : formules, termes et constantes. Ces bases servent de **source technique unique** et ne dupliquent pas les règles métier.
Chaque formule destinée au code conserve un identifiant stable (`combat.melee.hit_probability`, etc.). Une vue **Combat V1** regroupe désormais les formules de combat actives sans mélanger les formules de personnage ou d’équipement.
