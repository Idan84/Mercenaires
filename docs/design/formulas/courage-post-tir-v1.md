# Courage post-tir V1

Code: combat.ranged.courage_resolution
Domaine: Combat
Expression: if any_wound_inflicted: wounded_target resolves normal courage hold test vs shooter; if no_wound_inflicted: shooter makes no courage test
Notes: Contrairement au CAC, rater ou ne pas blesser avec un tir ne provoque jamais de test de Courage chez le tireur.
Statut: Validée
Type attaque: Distance
Version: V1
Étape: Autre

Après une séquence de tir :

- si une cible a réellement été **blessée**, elle utilise le test de Courage normal face au tireur ;
- si personne n'a été blessé, **aucun test de Courage n'est effectué par le tireur**.

Cette règle s'applique également lorsqu'un projectile raté blesse accidentellement un autre personnage : c'est le personnage réellement blessé qui teste.
