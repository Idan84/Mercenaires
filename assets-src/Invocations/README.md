# Invocations

Portraits des créatures invoquées (`data/reference/summon-archetypes.json`), un fichier par créature, nommé par son **code** :
`specter.jpg`, `raven.jpg`, `wolf.jpg`, `bear.jpg`, `crocodile.jpg`. Le zombie (Résurrection des morts) garde le portrait du mort relevé.
La liste, avec ce qui manque : Design Lab, onglet **Images**.

Le jeu n'affiche pas encore d'image de créature : JC3 branche l'affichage à l'arrivée des premières images.
