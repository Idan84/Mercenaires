# Filets

Les filets de la charte : un trait épais près de son motif qui s'affine jusqu'à disparaître, et entre dans le motif par le milieu.

- `brand` : le titre de l'en-tête (style `marque`, `or-clair`) entre deux filets `or` qui entrent dans une pointe de lance.
- `rule` : la ligne des étapes, le numéro au milieu, filets `or`.
- `message` : la réplique de Cruxor (style `replique`, `ivoire`, ombre `ombre-replique`), un `fil-centre` `or` dessous.
- `parch-head` : l'en-tête du parchemin entre deux filets courts `encre-secondaire`.
- `divider` : deux filets `encre-secondaire` qui entrent dans un motif : fleur de lys (`orn` avec `--orn`), couronne (`losange`, l'élément garde ce nom).
- `fiche-titre` : un titre en capitales (style `titre-fiche-parchemin`) entre deux filets qui entrent dans une pointe de lance.
- Les filets et motifs sont des SVG noirs (groupe Ornements de la charte) utilisés en masque : la couleur vient toujours d'un jeton.
