# Tirage de l’ascendance

Entrées: Peuple + probabilité d’ascendance + compatibilités + niveaux d’ascendance + contexte capitaine éventuel
Ordre: 4
Règle: Create_Mercenary : jet de présence d’ascendance inchangé. Si oui, tirage parmi les ascendances compatibles ; poids uniformes par défaut, sauf si le mercenaire a le même peuple que le capitaine et que le capitaine possède une ascendance : le poids du type d’ascendance du capitaine est alors ×2 s’il est compatible. Puis tirage normal du niveau. Create_Captain_Mercenary : le joueur choisit s’il veut une ascendance ; si oui, type tiré parmi les compatibles et niveau fixé à 3.
Sortie: Ascendance éventuelle + niveau
