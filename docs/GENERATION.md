# Génération des personnages

## Pipeline V1

1. Caractéristiques brutes : caractéristiques fondamentales = `20 + 3D20`; résistances = `1D6`.
2. Tirage du peuple.
3. Application des modificateurs de caractéristiques / résistances du peuple, collecte des modificateurs de compétences.
4. Tirage d'ascendance et intensité.
5. Application des modificateurs d'ascendance, collecte des modificateurs de compétences.
6. Tirage de culture.
7. Application des modificateurs de culture, collecte des modificateurs de compétences.
8. Tirage d'origine sociale.
9. Application des modificateurs d'origine, collecte des modificateurs de compétences.
10. Génération brute des compétences.
11. Application des modificateurs numériques de compétences.
12. Post-traitement : PV, mana, réputation personnelle initiale, salaire demandé.

Les distributions de base doivent plus tard être pondérées par la renommée de compagnie.

## Peuples — probabilités de base

Humain 20%; Elfe 15%; Nain 15%; Orc 15%; Gobelin 8%; Halfling 7%; Gnome 7%; Ogre 3%; Reptilien 5%; Homme-bête 5%.

## Ascendance

Chance de base : 20%.
Intensité : 40% Lointain, 40% Lignée proche, 20% Bâtard.

## Escouade initiale

Taille selon le peuple du capitaine :
- Ogre : sans ascendance `1D3+1`, avec ascendance `1D3`.
- Elfe / Reptilien / Homme-bête : `2D6+3` / avec ascendance `2D6`.
- Nain / Orc / Humain : `3D6+4` / avec ascendance `3D6`.
- Gnome / Gobelin / Halfling : `4D6+6` / avec ascendance `4D6`.

Les membres de l'escouade initiale ont peuple et culture forcés au capitaine ; le reste suit la génération normale.
