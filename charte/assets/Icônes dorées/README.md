# Icônes dorées

Le kit doré d'Idan (2026-11-25) : 23 icônes en or vieilli.

- Actions : `plus`, `moins`, `coche`, `croix`, `actualiser`, `agrandir`, `loupe`, `filtre`, `retour-rapide`, `avance-rapide`.
- États : `cadenas-ferme`, `cadenas-ouvert`, `info`, `question`, `attention`.
- Choix : `rond-vide`, `rond-coche` (un parmi plusieurs), `case-vide`, `case-cochee` (plusieurs).
- `triangle-gauche|droit|haut|bas` : les petites flèches (listes déroulantes, tris).
- Auteur : Idan.
