# Permutation de set d'armes V1

Code: http://combat.equipment.switch_weapon_set
Domaine: Combat
Expression: character has 2 prepared_weapon_sets; spend one quick_action => active_weapon_set = other_prepared_set
Notes: Deux sets d'armes sont préparés avant le combat. Changer de set en combat coûte une Action rapide. Les règles normales de prise, deux armes, inertie et état chargé/déchargé s'appliquent ensuite au set actif.
Statut: Validée
Type attaque: N/A
Version: V1
Étape: Équipement

## Principe

Un personnage dispose de **2 sets d'armes préparés**.

**Changer de set = 1 Action rapide.**

Le changement remplace les objets tenus du set actif par ceux de l'autre set préparé. Le nouveau set utilise ensuite toutes les règles normales de prise, combat à deux armes, vitesse et armes à feu.

L'état propre d'une arme est conservé : passer un pistolet déchargé dans le set inactif ne le recharge pas.
