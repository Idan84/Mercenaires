# Modificateurs d’origine sociale

Entrées: Origine sociale + Matrice de génération + Échelle D6
Ordre: 9
Règle: Lire les intensités signées de l’origine sociale. Appliquer caractéristiques / résistances ; mémoriser les modificateurs de compétences. Après cette étape, le profil identitaire est complet et permet de générer les compétences brutes.
Sortie: Caractéristiques/résistances finales + modificateurs de compétences complets
