# Curseurs dorés

Le kit doré d'Idan (2026-11-25) : les curseurs de souris en or vieilli (grands, pour la charte ; un curseur de souris se sert à 32 px avec son point actif, à préparer en PNG).

- `pointeur`, `main-index` (cliquable), `main-ouverte` (on peut saisir), `main-saisie` (on tient), `sablier` (attente), `deplacer`, `redim-horizontal|vertical|diagonale-1|diagonale-2`, `actualiser`.
- Auteur : Idan.
