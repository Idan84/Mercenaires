# Velours

Le velours rouge du kit doré d'Idan (2026-11-25), seul : `panneau-velours.webp` (1200 × 230, pans coupés) et `disque-velours.webp` (591 × 600). Il se pose sous un cadre doré et se teinte comme celui des boutons. Pas encore de velours raccordable (qui se répète sans couture) pour les grandes surfaces.
