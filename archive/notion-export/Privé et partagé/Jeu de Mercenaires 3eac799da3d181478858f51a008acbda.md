# Jeu de Mercenaires

Spécification de référence du jeu de mercenaires. L’objectif est de garder **une seule source de vérité par mécanique**, suffisamment claire pour être implémentée directement dans le moteur JS.

Organisation : démarrage de partie → génération du mercenaire → état du personnage → combat → équipement → référentiels techniques → architecture des objets persistants.
