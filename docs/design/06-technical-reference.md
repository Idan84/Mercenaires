# Référentiels techniques

Registres transversaux du moteur : formules, termes et constantes. Ils sont la **source technique unique** et ne
dupliquent pas les règles métier.

Chaque formule destinée au code garde un identifiant stable (`combat.melee.hit_probability`, etc.).

- Formules : `docs/design/formulas/` et `data/reference/game-formulas.json` ;
- termes de formule : `data/reference/formula-terms.json` ;
- constantes de formule : `data/reference/formula-constants.json`.
