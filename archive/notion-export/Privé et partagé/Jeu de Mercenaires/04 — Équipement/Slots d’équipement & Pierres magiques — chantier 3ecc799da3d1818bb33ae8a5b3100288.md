## Slots envisagés

- **Casque / Chapeau** : protection, avec éventuelle perte de Perception ; certains modèles pourront au contraire soutenir / amplifier la magie.
- **Amulette** : Résistances, Courage et effets défensifs / mentaux.
- **Armure** : système déjà défini dans les référentiels actifs.
- **6 Bagues** : effets très variés. Le nombre utilisable pourra dépendre de l'intégrité physique du personnage — Marcel qui perd une main perd logiquement des doigts exploitables.
- **Bottes** : Vitesse / mobilité en priorité.
- **Ceinturon** : slot distinct, propriétés à définir.
- **Cape** : défensive, utilitaire, magique, camouflage, etc.
- **2 sets d'armes** : deux configurations préparées. La permutation est désormais une règle active : [Permutation de set d'armes V1](../05%20%E2%80%94%20R%C3%A9f%C3%A9rentiels%20techniques/Formules%20de%20jeu/Permutation%20de%20set%20d'armes%20V1%203ecc799da3d1817dbe21fd70f8711f59.md) coûte **1 Action rapide**.
- **4 équipements de ceinture** : consommables / petits objets actifs, par exemple potions.
- **1 Monture / Animal de combat** : slot dédié ; les règles de montures et compagnons viendront plus tard.

## Enchantement au camp — Pierres magiques

Les objets pourront être **enchantés au camp** via des Pierres / Gemmes magiques.

Principe structurant : **la combinaison compte autant que les pierres elles-mêmes**. Deux pierres couplées peuvent produire un effet spécifique plutôt qu'une simple addition de bonus.

Exemples de direction :

- `Gemme de Feu + Gemme de Résistance` → effet défensif / résistance élémentaire lié au feu ;
- `Gemme de Feu + Gemme de Dégâts` → effet offensif / amplification feu.

Inspiration de structure assumée : logique de combinaisons proche des Matérias de Final Fantasy VII, sans figer pour l'instant les valeurs ni les recettes.
