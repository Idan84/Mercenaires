# Ornements de la charte

- `lance.svg` (pointe de lance des épées ailées), `couronne.svg`, `fleur-de-lys.svg` : pris dans les ornements d'Idan (`prototype-web/assets/creation/svg/`).
- `fil.svg` (s'affine vers la gauche), `fil-centre.svg` (épais au milieu), `fil-v.svg` (vertical), `croix.svg` (la croix tracée à la plume), `chevron.svg`, `losange.svg` (les étapes) : dessinés pour la charte (dans `prototype-web/creation-capitaine.css`).
- Une seule encre : noir. Toujours utilisés en masque ; la couleur vient d'un jeton (`encre-secondaire` sur le parchemin, `or` sur la scène).
