# Ennemis types

Portraits des ennemis types (`data/reference/enemy-archetypes.json`), un fichier par type, nommé par son **code** :
`goblin_spearman_novice.jpg`, `goblin_chief_1.jpg`… La liste complète, avec ce qui manque : Design Lab, onglet **Images**.

Le jeu n'affiche pas encore d'image d'ennemi (les pions montrent leurs initiales) : JC3 branche l'affichage à l'arrivée des premières images.
