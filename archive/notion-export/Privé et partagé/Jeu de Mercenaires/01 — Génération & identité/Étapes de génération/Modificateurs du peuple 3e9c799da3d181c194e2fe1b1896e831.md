# Modificateurs du peuple

Entrées: Peuple + Matrice de génération + Échelle D6
Ordre: 3
Règle: Lire les intensités signées du peuple dans la matrice. Appliquer immédiatement les effets sur caractéristiques / résistances. Pour les compétences, mémoriser les modificateurs afin qu’ils puissent d’abord influencer le tirage brut puis être appliqués numériquement après initialisation.
Sortie: Caractéristiques/résistances après peuple + modificateurs de compétences collectés
