# Pictos du camp

- `picto-or.webp`, `picto-mercenaires.webp`, `picto-salaires.webp` : les chiffres de la barre du haut.
- `next.webp` : le bouton du jour suivant, au centre de la barre du bas.
- `bas-<lieu>.webp` (200 × 200) : les boutons de la barre du bas (château, combat, construction, discussions, dortoir, intendance, journal, marchand, nouvelles, taverne) ; le lieu actuel est grisé.
- Fournis par Idan (pack de la barre du camp) ; source dans le jeu : `prototype-web/assets/hud/`.
