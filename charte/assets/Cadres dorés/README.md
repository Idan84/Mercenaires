# Cadres dorés

Le kit doré d'Idan (2026-11-25), cadres seuls (intérieur transparent), en `border-image` : coins jamais déformés, côtés étirés.

- `cadre-large.webp` (1200 × 261) : le grand cadre aux pans coupés, moulure épaisse ; bandeaux, cartouches, gros boutons.
- `cadre-fin.webp` (1200 × 159) : le même en moulure fine ; champs, lignes de liste, petits boutons.
- `cadre-carre.webp` (596 × 600) : carré aux pans coupés ; vignettes, cases d'inventaire, pictos.
- `cadre-vertical.webp` (193 × 1200) : la colonne aux pans coupés ; barres de défilement, jauges verticales (un petit nœud au milieu de chaque côté : à garder au centre, ou couper au-dessus).
- `anneau.webp` (593 × 600) : l'anneau ; médaillons, boutons ronds.
- `coin-orne-haut-gauche|haut-droit|bas-gauche.webp`, `coin-bas-droit.webp` (800 px) : les grands coins de panneau, avec rinceaux ; le coin bas-droit n'a pas de rinceaux (à refaire), et les bras n'ont pas tous la même épaisseur (72 à 102 px).
- Auteur : Idan.
