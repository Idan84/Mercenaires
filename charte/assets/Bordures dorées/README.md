# Bordures dorées

Le kit doré d'Idan (2026-11-25) : les pièces pour tracer des cadres et des séparations en or.

- `barre.webp` : la barre droite ; `coin-arrondi`, `coin-equerre`, `te`, `croix` : les jonctions.
- `embout-pointe-gauche|droite`, `embout-rond-gauche|droit` : les bouts de barre ; `noeud-losange` : le nœud.
- `filet-losange`, `filet-deux-losanges`, `filet-trois-losanges` : séparations courtes ; `separateur-fin|volutes|entrelacs|rinceaux` : séparations de titre (du plus sobre au plus orné).
- Auteur : Idan.
