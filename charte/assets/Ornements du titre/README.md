# Ornements du titre

- Un ornement par culture (32 ; `assets.json` dit lesquelles), SVG 104 × 24, une seule encre : noir (#000). Le jeu s'en sert comme masque et le peint en `hc-parchemin`, à gauche du titre de la fiche au survol, et en miroir à droite.
- Le motif est côté titre (à droite de la boîte) ; un filet effilé y entre parfois ; la ligne médiane (y = 12) se pose sur le milieu des minuscules du titre.
- Deux sortes : découpés dans les planches d'ornements d'Idan, ou formes simples dessinées pour le jeu (flocon, fleur, triangle, croissant, marteau…), sans droits.
- Refaits par `scripts/build-title-ornaments.py` ; source dans le jeu : `prototype-web/assets/fiche/ornements/<motif>.svg`.
